# 轻跑计划 · Running, gently

一个基于 Soft Neutral Interface 设计规范制作的轻量跑步计划网站。

## 功能

- 2026-10-15 至 2027-01-01 跑步日历
- 38 个跑步日，每个跑步日安排两次，共 76 次
- 41 个完整休息日，跑步日均匀分布
- 两次跑步独立打卡、进度统计
- 深色 / 浅色主题
- 响应式布局、键盘焦点、减少动态效果支持
- 打卡数据只保存在当前浏览器的 localStorage，不上传到服务器

## GitHub Pages

仓库目前为 Private。GitHub Pages 的可用性取决于仓库可见性与 GitHub 账号套餐。若当前套餐不支持从私有仓库发布 Pages，需要将仓库改为 Public，或选择其他静态托管服务。

仓库具备 Pages 部署条件后，在 Settings → Pages → Build and deployment 中将 Source 设为 GitHub Actions。之后推送到 main 会自动部署。
